## 1. 產品概要

一個給台灣多益考生用的單字與練習網站，三個核心：

| 核心 | 內容 |
|---|---|
| 背單字 | 1000 個多益單字（400／600／800／990 四級，各 250 字），仿 Anki 的間隔複習單字卡 |
| 練習題 | 仿多益題型的原創題：單字填空（Part 5）1200 題（單字題 666、詞性題 334、文法題 200）、短文閱讀（Part 6／7）120 篇 360 題、聽力應答（Part 2）400 題；每題有解題關鍵和各選項解析 |
| 估分 | 約 40 題的適性落點測驗，加上依平常練習持續估分 |

技術：純靜態網站（HTML／CSS／原生 JavaScript，沒有框架、沒有建置步驟、沒有後端），放在 GitHub Pages。登入與跨裝置同步用 Firebase（Google 登入＋Firestore）。發音用瀏覽器內建的 Web Speech API。可離線使用（Service Worker）。

存取控制：線上版要用 Google 帳號登入，並經管理員同意才能使用（第 10.5 節）。

不做的事：不收費、沒有帳號以外的個資、不放多益真題或出版社題目、不用簡體中文。

## 2. 使用者與設計原則

- **主要使用者**：一位台灣上班族，多益約 300–400 分，準備考試以爭取外商工作。幾乎都用 iPad 和手機。
- **手機優先**：所有畫面先確定在 390px 寬（iPhone）和 320px 寬（小手機）不會橫向捲動，再看桌機。
- **繁體中文（台灣用語）**：介面、解析、翻譯一律繁體；不使用中國用語。
- **一次只給需要的資訊**：例如單字卡下方的提示一次只顯示一種；解析可以設定成先收起來。
- **誠實**：估分會標明是粗估；題目標明是原創題；解析經過查核但不保證完全正確。
- **內容品質優先於數量**：題目答案經獨立盲解核對，解析經兩輪查核（見第 11 節）。

## 3. 系統架構

### 3.1 檔案

| 檔案 | 職責 |
|---|---|
| `index.html` | 頁面骨架：級別分頁（400／600／800／990／全部／自選）＋六個檢視（學習、練習、單字庫、統計、設定、說明）。script 載入順序見 3.2 |
| `css/style.css` | 全部樣式。刷刷庫風格配色；桌機左側直排分頁，寬度 ≤ 720px 改成上方 6 格分頁列 |
| `js/srs.js` | `window.SRS`：間隔複習排程（第 5 節） |
| `js/app.js` | 主程式：狀態載入與儲存、單字卡、單字庫、統計、設定、匯入匯出、自選單字、同步合併、單字卡提示行；並把共用功能以 `Practice.init(T)` 傳給練習頁 |

| `data/aids.js` | 單字卡的自然發音與字根字首（第 9.4 節），設定或切換到這兩種提示時才載入 |
| `sw.js` | Service Worker：快取、離線、更新（第 12 節） |
| `manifest.webmanifest`、`icons/`、`favicon.ico` | 加到主畫面用。圖示是看書的兔兔，由 `tools/scripts/icon_gen.py` 產生（照使用者提供的圖描成向量；`icons/icon.svg` 是原始檔，分頁用的 32px 版本把圖放大、線加粗） |
| `README.md` | 對外的專案說明與 Firebase 設定步驟 |
| `tools/` | 不屬於網站：交接文件、這份規格書、建置腳本、內容原始檔、測試（見 `HANDOFF.md`） |

### 3.2 模組之間的關係

```
index.html 依序載入（全部是一般 <script>，沒有模組）：
  1. data/words.js        → window.WORDS
  2. js/srs.js            → window.SRS（不依賴別人）
  3. Firebase compat SDK  （gstatic CDN：app、auth、firestore 10.14.1）
  4. js/firebase-config.js
  5. js/sync.js           → window.Sync；透過 hooks 回呼 app.js（取狀態、合併遠端、重畫）
  5b. js/gate.js          → 使用權限的畫面（訂閱 Sync.onStatus）
  6. data/quiz_meta.js    → 題數
  7. js/score.js          → window.ToeicScore
  8. js/practice.js       → window.Practice；只透過 T（app.js 給的介面）讀寫狀態
  9. js/app.js            → 最後載入：建立 state，呼叫 Sync.init(hooks)、Practice.init(T)，畫出畫面
```

- `app.js` 給練習頁的介面 `T`：`state()`、`save()`、`notePractice()`、`notePlace()`（標記要同步的欄位）、`todayKey()`、`esc()`、`toast()`、`byId`、`rec(id)`、`setRec(id, r)`、`SRS`、`levelFilter()`、`levelName()`、`lvLabel()`、`level()`、`switchLevel(lv)`、`words()`、`baseCount`、`customId()`、`addCustom()`、`removeCustom()`、`prioritize()`、`speak()`、`speakSeq()`、`stopSpeech()`、`canSpeak()`、`phonHtml()`、`SPK`（喇叭圖示）、`renderTabs()`、`isActive()`。練習頁不直接碰 `localStorage` 或 Firebase。
- 狀態只有一份（`app.js` 的 `state`），存在 `localStorage` 的 `toeic-cards-v1`。任何修改後呼叫 `save()`：寫回 localStorage，並把這次改到的欄位交給 `Sync.noteChange()`，約 1.5 秒後批次寫到 Firestore。
- 大的資料檔一律用動態 `<script>` 延遲載入（題庫、小字典、aids），不在首頁載入時下載。

### 3.3 執行環境

- 現代瀏覽器（iOS Safari、Chrome、Edge）。不需要安裝、沒有建置。
- 本機開 `index.html`（`file://`）就能用；只有 Google 登入需要在 `mitsuiwei.github.io`（Firebase 已授權的網域）。

## 4. 畫面與功能規格

### 4.1 共用版面

- **級別分頁**：400、600、800、990、全部、自選。切換會改變單字卡、單字庫、練習題的範圍（練習頁「自選」沒有題庫）。切換時結束進行中的練習回合，但**不會**中斷落點測驗。
- **檢視切換**：學習、練習、單字庫、統計、設定、說明；管理員多一個「管理」（第 4.10 節）。目前所在檢視記在 `state.view`。
- 小提示訊息用 `toast()`，約 2 秒後消失。

### 4.2 學習（單字卡）

- 頂端計數：今天還能學的新字、學習中、今天到期的複習；「復原上一張（Z）」。
- **卡片**：
  - 方向（設定）：看英文想中文（預設）／看中文想英文。
  - 正面：單字＋詞性＋**提示行**＋例句（設定：顯示並標橘色／顯示並把單字挖空／不顯示在正面）。看中文想英文時，正面是中文意思。
  - 按「顯示答案」或空白鍵翻面，背面是中文意思（多個詞性逐行列出）、例句、例句翻譯。
  - 單字和例句可點擊發音（喇叭圖示）。新卡出現時自動唸單字、翻面時自動唸單字或單字＋例句（設定）。
- **提示行（設定「單字提示」，一次只顯示一種）**：
  - KK 音標（預設）／自然發音／字根字首／不顯示。（原本還有 IPA，使用者要求拿掉；舊設定的 ipa 載入或同步時一律改成 kk。）
  - 自然發音：音節以 `·` 分開、重音節標橘色，下面一行是這個字最有用的一兩條發音規則。
  - 字根字首：各部分上下排列「部分／意思」，用「＋」連接，下面一行說明怎麼連到字義。**會透露意思，所以只在翻面後出現**，翻面前先顯示 KK 並註明「翻面後看字根字首」。
  - 沒有自然發音或沒有可靠字根拆法的字：顯示 KK，並以小字註明。
  - **點提示行可以臨時換成下一種**（KK → 自然發音 → 字根字首 → KK），只對這張卡有效，評分後恢復設定值。
  - 單字庫、練習頁的小卡固定顯示 KK。
- **評分**：重來／困難／良好／簡單（鍵盤 1–4），按鈕下方顯示各自的下次出現時間（第 5 節）。
- **這個字我早就會了，跳過**：只在新卡出現，標成「已會」，不再排程。
- **先挑掉已經會的字（快速篩選）**：一次一個字快速閃過，只問「認得（2）／不確定（1）」；認得 → 已會，不確定 → 保留為新字；可回上一個、隨時結束。
- **休息畫面**：沒有可複習的卡但有學習中的卡在等時，顯示還要等幾分鐘，提供「不等了，現在複習（空白鍵）」。新字額度用完時提供「再多學 10 個」。
- 自選分頁沒有字時，說明怎麼在練習題裡存字。

### 4.3 練習

首頁：
- 最上方「多益落點測驗」卡片（上次結果、平常練習估計）。
- 三種題型卡片：單字填空、短文閱讀、聽力應答，各顯示題數與做過的比例；錯題分析入口。
- 單字填空的範圍（設定 `practiceScope`）：只出學過的字（預設）／全部。學過的字不夠 10 題時用還沒學的補滿。
- 沒有語音的瀏覽器不顯示聽力。

一回練習：
- 單字填空、聽力 10 題一回；短文 1 篇（3 題）一回。出題規則見第 6 節。
- 單字填空有三種題：單字題、詞性題、文法題（動詞、介系詞、連接詞／介系詞／副詞、代名詞、關係詞與其他）。題目上方有標籤。每回 10 題固定帶 2 題文法題。文法題沒有對應的單字：回饋框沒有單字那一行，答錯也不會排回單字卡。
- 作答後立刻顯示對錯，正解綠、選錯紅，回饋框有「解題關鍵」，每個選項底下有**各選項解析**：
  - 單字填空：詞性、中文、常考用法、為什麼對／錯。
  - 短文閱讀：中文、用法、為什麼對／錯。
  - 聽力：陷阱類型、為什麼對／錯；作答後顯示文字稿。
  - 設定 `explain`：直接顯示（預設）／先收起來（按「看解析」才展開，換題自動收回）。
- 單字填空作答後，回饋框裡顯示「英文整句（答案加粗）在上、中文翻譯在下」；點英文或中文都會唸英文，**唸到哪個字那個字就亮起來**（逐字標示）。瀏覽器有送語音的 boundary 事件時照事件標（iOS／macOS Safari、本機語音）；沒送時（Android Chrome、Chrome 的線上語音）依字長和語速估時間。錯題分析和落點測驗結果裡的單字填空題也一樣。
- 單字填空答錯時，把那個字排回單字卡（複習中的字 → 當作按了「重來」；已會的字 → 改回新字），並提示。
- 題目、選項、文章裡的英文字都能點（第 8 節）。
- 聽力：自動唸問句再唸 A、B、C；可重聽（R）。
- 鍵盤：1–4 或 A–D 作答、Enter 下一題、R 重聽、Esc 關閉小卡。
- 一回結束顯示得分、答錯的題目，可再來一回。

錯題分析：
- 依題型統計「最近一次作答」的答對率，再細分到類型（單字題／詞性題、Part 6、主旨／細節／推論／NOT／字義題、各種聽力問句），標出最弱的一類並給該類的作答提示。
- 列出錯題（當時選的、正確答案、解析），可「只重做錯題」。

### 4.4 落點測驗

見第 7 節。介面流程：說明頁（題目組成、作答方式、過去結果）→ 作答（不顯示對錯；選一個選項後按「下一題」，可改選；聽力只播一次，聲音沒出來可重播一次；可中途結束，不算分）→ 結果頁（總分區間、聽力／閱讀區間、各題型答對率、弱點分類、建議級別按鈕、答錯題目與解析、說明這是粗估）。

### 4.5 單字庫

- 搜尋（英文或中文）、狀態篩選（全部、新字、學習中、複習中、已會、停用、常忘＝忘記 2 次以上）。
- 每個字：發音、提示（KK／IPA）、意思、狀態；操作：標成已會、停用、重置為新字；自選的字可移除。
- 一次顯示 80 個，「顯示更多」每次加 100。

#### 連續播放（v25）

把單字庫目前列出來的字（級別、搜尋、狀態篩選之後的順序）一個一個唸出來。參考使用者自己的另一個網站 `websec.one/toeic/vocab.html` 做的；那個網站播的是錄音檔，這裡用裝置的語音合成。

- **工具列**（搜尋列下面）：
  - 顯示方式：全部顯示／遮中文／遮英文。遮住的一邊是灰色塊，點一下顯示（遮英文時音標一起遮）。換顯示方式會把已揭曉的重新遮回去。
  - 唸哪一種：英＋中／只唸英文／只唸中文。
  - 連續播放／暫停、自動跟隨（開關）、語速（跟設定頁的語速是同一個值）。
- **每一列前面的播放鈕**：連續播放中按＝跳到那個字接著播；沒在播時按＝只唸那個字（不揭曉）。點單字本身還是原本的「只唸英文」，而且會讓連續播放停下來。
- **一個字的流程**（`libSteps()`）：
  - 沒有遮：英文 → 0.25 秒 → 中文（依「唸哪一種」省略其中一邊）。
  - 有遮（連續播放時）：唸看得到的那一邊 → 想 2.2 秒÷語速（遮罩會閃）→ 揭曉 → 唸剛揭曉的那一邊。沒被選到的語言就跳過那一步，例如「遮英文＋只唸英文」是：想 → 揭曉 → 唸英文。
  - 字跟字之間停 0.6 秒÷語速。唸完最後一個字自動停。停頓用的語速最低算 0.5（`libPace()`），語速調到 0.2 時不會等到十幾秒。
- **語音**：英文用設定的英文語音和語速；中文用裝置的中文語音（`zhVoice()`：台灣國語優先，其次其他國語，不用粵語），語速固定 1。中文唸的是各詞性的中文意思，用「，」接起來。裝置沒有中文語音時那一步會直接略過。
- **正在唸的字**：那一列橘色底＋外框，換到那一列時放大一下再縮回（`lp-arrive`）；唸到英文或中文時，那一邊底下有一條線掃過去；播放鈕變成跳動的三條線。
- **自動跟隨**：換字時如果那一列不在畫面中段，就平滑捲到中間（`libLocate()`）。唸到還沒列出來的字（清單一次只列 80 個）會自動多列。
- **底部控制列**（`#lpNow`，有正在唸的字時滑上來）：上一個、播放／暫停、下一個、第幾個／共幾個、目前的字（遮英文還沒揭曉時顯示「？？？」）、定位（那一列不在畫面裡時會亮）、進度線。
- 連續播放時會要求螢幕恆亮（Wake Lock，瀏覽器不支援就略過）；螢幕關掉或切到別的 App，手機瀏覽器就不會再唸，這是語音合成的限制。
- 會停止的情況：按暫停、離開單字庫、正在唸的字被搜尋或篩選篩掉、點了其他會發音的東西。
- 顯示方式、唸哪一種、自動跟隨存在 `localStorage['toeic-lib-v1']`，只在這台裝置，不同步。
- 鍵盤：空白鍵 播放／暫停、J／← 上一個、K／→ 下一個、G 捲到正在唸的字。
- 程式在 `js/app.js` 的「單字庫：連續播放」一段（`lib` 物件和 `lib*` 函式），樣式在 `css/style.css` 最後的 `.lp-*`。

### 4.6 統計

- 估計多益分數（依平常練習，第 7.4 節）與「做落點測驗」按鈕。
- 今天：複習張數、新學、答對率、連續天數。
- 練習：今天題數與答對率、各題型累計。

## 5. 排程演算法（`js/srs.js`）

仿 Anki 的 SM-2 變體。

- 卡片狀態：`new`、`learning`、`relearning`、`review`、`known`（使用者標記早就會了，不排程）、`suspended`（停用）。
- 參數：學習步驟 1 分鐘 → 10 分鐘；重學步驟 10 分鐘；良好畢業 1 天、簡單畢業 4 天；最長間隔 365 天；難易度係數 `ef` 初值 2.5、最低 1.3。
- 學習／重學中：重來 → 回第一步；困難 → 停在目前步驟，間隔取目前與下一步的中間；良好 → 下一步，走完就畢業；簡單 → 直接畢業。
- 複習中：重來 → `lapses+1`、`ef−0.2`、間隔歸 1 天、進入重學；困難 → `ef−0.15`、間隔 ×1.2（至少 +1 天）；良好 → 間隔 × `ef`（至少 +1 天）；簡單 → `ef+0.15`、間隔 × `ef` × 1.3（至少比良好多 1 天）。
- 複習卡的到期時間定在目標日 00:00（當天任何時候都算到期）；3 天以上的間隔加小幅隨機（避免同一天學的卡永遠一起到期）。
- 佇列：到期的學習卡 → 到期的複習卡 → 新卡（受每天新字額度限制）。沒卡可複習時，自動提前抓 2 分鐘內到期的學習卡。
- 新卡順序：照單字表或隨機；在練習題裡按過「存起來」的字表字（`pri`）排最前面，先存的先出。

## 6. 練習的出題規則（`practice.js` 的 `pick()`）

- 範圍：目前級別（「全部」= 四級）；單字填空另受「只出學過的字」限制。
- 題目分四堆：沒做過（隨機）、最近一次答錯（久沒做的先）、最近一次答對（久沒做的先）、範圍外（只用來補）。
- 單字填空的文法題另外挑、不受「只出學過的字」限制：每回 `GRAM_PER_ROUND` = 2 題（之前錯的最多 1 題 → 沒做過的 → 答對過最久沒做的），其餘 8 題照下面的規則挑單字題和詞性題。
- 單字填空／聽力：每回先放最多 3 題之前錯的，再放沒做過的，不夠再放其他錯的、答對的；最後打亂順序。範圍內不夠 10 題時用範圍外補（沒做過的優先），並告知補了幾題。
- 短文：沒做過 → 答錯過 → 答對過，取 1 篇。
- 「只重做錯題」：只出最近一次答錯的，久沒做的先。
- 每題作答都記進 `practice` 與 `pday`（第 10.1 節）。

## 7. 落點測驗與估分模型

### 7.1 測驗組成

聽力 15 題（Part 2）→ 單字填空 16 題（Part 5）→ 短文 3 篇 9 題（Part 6／7），共 40 題，約 15 分鐘。瀏覽器不支援語音時跳過聽力，只估閱讀。

### 7.2 適性出題

- 每一題出題前，用目前作答算出的估計（第 7.3 節）挑「資訊量最大」的級別（3PL 的 Fisher information），同級裡優先出沒做過的題，其次最久沒做的；該級用完找最近的級別。
- 聽力和閱讀各自估計、各自挑級別。短文一篇三題用同一級。
- 每題照常記進練習紀錄（錯題分析看得到）；單字填空答錯照常把字排回單字卡。

### 7.3 估分模型（`js/score.js`）

- 三參數試題反應理論（3PL）：`P(答對 | θ) = c + (1 − c) / (1 + e^(−a(θ − b)))`。
- `θ` 是單科分數（聽力或閱讀，5–495）。
- `b`（題目難度）**依級別假設，未經真實考生校正**：400 級 175、600 級 275、800 級 375、990 級 455。
- `a` = 0.025；`c`（猜對機率）四選一 1/4、聽力三選一 1/3。
- 在 5–495 每 5 分一格算後驗分布，先驗為常態（平均 250、標準差 125），取期望值（EAP）與標準差。
- 顯示「期望值 ± 1 標準差」（約七成把握），四捨五入到 5 分；總分 = 聽力 + 閱讀，標準差平方和開根號，範圍 10–990。
- 在模型本身的假設下模擬 40 題，總分誤差約 ±45 分（`tools/scripts/sim_place.js`）。實際誤差更大，介面上一律說明是粗估。
- 建議級別：總分 < 350 → 400；350–549 → 600；550–749 → 800；≥ 750 → 990。只測閱讀時用閱讀 × 2。

### 7.4 平常練習估分

- 每一題只看「第一次就答對」：作答次數 = 答對次數才算對；短文用平均答對題數近似。
- 兩科各取最近 60 題，各至少 10 題才顯示；不足時顯示還差幾題。
- 顯示在統計頁上方與練習首頁的落點測驗卡片。

## 8. 點字查詢與自選單字

- 練習頁的英文字以 `<span class="tw">` 包起來。點一下跳出小卡：原形、發音、KK、中文意思。
- 查詢順序：字表（`WORDS`）→ 小字典的變化形對照（`GLOSS.f`）→ 小字典詞條（`GLOSS.w`）。拼法和字表撞到但意思不同的字（`ALT` 表，例如 minutes、found）會多一行「也可能是另一個字」。
- 接在稱謂（Mr.、Ms.…）或人名後的大寫字、`GLOSS.n` 列的專有名詞，視為人名或地名，不提供存字。
- **點字不會存**；小卡上按「存起來」才存：
  - 字表內的字：標記 `pri`，新字佇列排最前面（第 5 節）。
  - 字表外的字：加入「自選」單字（`custom`），和字表的字一樣排程；例句取自題目。
  - 已存過的可以取消（復原）。
- 自選單字 id 為 `c_` + 原形，接在 `WORDS` 陣列後面（`lv: 'my'`、`custom: true`），由 `rebuildCustom()` 依狀態重建。

## 10. 狀態與同步規格

### 10.1 本機狀態（`localStorage['toeic-cards-v1']`）

                       pri = 在練習題按「存起來」的時間（取消時設為 0）

字表的字 id 是數字，自選的是字串 `c_…`；從畫面讀 id 一律用 `idOf()`，級別用 `lvOf()`（可能是數字、`'my'`、`'all'`）。

### 10.2 雲端（Firestore）

- 文件 `toeicCards/{uid}`：`recs`、`settings`、`settingsUpdated`、`daily`、`practice`、`pday`、`custom`、`place`、`placeCleared`、`updated`。
- 複習紀錄另外放子集合 `toeicCards/{uid}/log/{YYYY-MM}`。
- 安全規則：只有本人（`request.auth.uid == uid`）能讀寫自己的文件（規則全文在 `README.md`）。同一個 Firebase 專案還有使用者的另一個網站，改規則時只加 `toeicCards` 那一段。

### 10.3 同步規則（`sync.js`、`app.js` 的 `mergeRemote()`）

- 登入後先讀遠端整份文件合併到本機，再把合併結果整份推上去；之後監聽遠端變更（另一台裝置寫入時即時合併）。
- 本機修改：`save()` 時記下改到哪些欄位，約 1.5 秒後只寫那些欄位（`set(…, { merge: true })`）。
- 合併原則「每一筆看時間戳，新的贏」：
  - `recs` 看 `last`；`practice` 看第 3 欄；`pday`、`custom` 看 `t`；`settings` 看 `settingsUpdated`；`log` 取聯集。
  - `place` 取聯集（結果只增不改）；`placeCleared` 取較大值，並刪掉 `t` 不大於它的結果。
  - 先合併 `custom` 再合併 `recs`（自選字的紀錄要有字可掛）。
- 因為 `merge: true` 是深層合併，要「清掉」的欄位必須明確寫成 0（例如 `pri: 0`、`del: 0`），不能靠刪 key。
- 未登入時一切照常，只存在本機；登入後自動合併。

### 10.5 使用權限

- Firestore 文件 `toeicAccess/{uid}`：`{ email, name, status: 'pending' | 'approved' | 'denied', requestedAt, decidedAt }`。
- 規則（全文在 `README.md`；實際生效的那一份在 Firebase Console，管理員信箱只寫在那裡，**不放進這個公開的 repo**）：
  - 只接受 Google 登入（`sign_in_provider == 'google.com'`）。
  - `toeicAccess/{uid}`：本人可讀自己的、只能建立 `status: 'pending'` 且 email 等於登入帳號的申請；list／update／delete 只有管理員。
  - `toeicCards/{uid}`（含 `log`）：本人且已核准（或是管理員）才能讀寫；管理員可以讀所有人的、不能寫別人的。
- 前端判斷（`sync.js` 的 `checkAccess()`／`applyAccess()`）：
  - 管理員：登入後試著向伺服器列出 `toeicAccess`（`get({ source: 'server' })`），成功就是管理員。程式裡沒有管理員信箱。
  - 一般人：讀自己的 `toeicAccess/{uid}` → 沒有＝`none`、`pending`、`denied`、`approved`＝`ok`；並用 `onSnapshot` 監聽，狀態一變畫面就跟著變。
  - 讀自己的申請單被拒（`permission-denied`）代表規則還沒更新 → `dormant`：登入就放行，設定頁顯示「審核還沒啟用」。這樣先上線程式、後更新規則也不會把人鎖在外面。
  - 其他錯誤（離線）：這台裝置核准過（有 `toeic-gate-v1`）就放行，否則 `unavailable`。
  - 沒通過時不啟動同步、不排隊上傳。
- `Sync.gate()` 回傳 `{ on, state, admin, dormant, msg, reqs, user }`；`state`：`off`／`checking`／`nosdk`／`signed-out`／`none`／`pending`／`denied`／`unavailable`／`ok`。管理員另有 `Sync.decide(uid, status)`、`Sync.removeAccess(uid)`、`Sync.loadUser(uid)`。
- **這是前端的門**：擋的是一般訪客。網站程式和題庫放在公開的 GitHub Pages（repo 也是公開的），懂技術的人仍然可以直接下載。伺服器真正把關的只有 Firestore 裡每個人的學習資料。要讓網站本身不公開，得搬到有存取控制的主機。

### 10.4 匯入匯出

- 匯出備份：整份 `state` 的 JSON。匯入時覆蓋本機，並把所有欄位標記為要同步。
- 匯出 Anki：TSV，欄位為單字、音標、意思、例句、翻譯、標籤（`TOEIC400` 等），開頭有 Anki 的設定行。
- 清除全部進度：卡片、練習、自選、落點結果全部歸零，並寫入 `placeCleared`，讓其他裝置同步清除。

## 12. 非功能需求

- **版面**：390px、320px 寬不可橫向捲動；桌機 1280px 正常。觸控目標夠大；手機寬度下練習頁不顯示鍵盤提示。
- **離線與更新**：Service Worker 預先快取所有頁面檔與資料檔（題庫、小字典、aids 都在快取清單裡）；採 stale-while-revalidate。每次上線把 `sw.js` 的 `VERSION` 加一，新版啟用後頁面自動重新整理一次。
- **效能**：首頁只載入單字資料；題庫、小字典、aids 用到才載入。
- **語音**：Web Speech API，聲音是裝置內建的。自動挑選時給每個英文語音打分數（`app.js` 的 `voiceScore()`）：美式優先，Apple 的高級／增強語音、Edge 的線上自然語音、Android 的 neural 語音加分，趣味語音和 Eloquence 語音排最後；瀏覽器規定第一次出聲前要有使用者點擊。沒有語音時隱藏聽力、落點測驗只測閱讀。
- **無障礙**：按鈕有 `aria-label`；選項有 `aria-pressed`；鍵盤可完成主要操作。
- **隱私與安全**：repo 公開，不放任何密碼或 Token；Firebase 瀏覽器端金鑰本就公開並限制了 referrer；Firestore 規則限制只能存取自己的文件。
- **語言**：繁體中文（台灣用語），英文內容以美式為準。

## 13. 已知限制與未來方向

- 估分的難度參數是假設的，未經真實考生校正；聽力只有 Part 2（沒有照片、對話、獨白）。有真實成績後可據以調整 `score.js` 的 `b`。
- 跨裝置同步只在本機測過合併邏輯，需要在真實裝置上驗證。
- 小字典約 94 個複合字沒有音標；單字卡例句裡的字不能點查（只有練習頁可以）。
- 可能的方向：用真實成績校正估分、圖像記憶（例如「我的聯想」欄位）、補 Part 1／3／4 聽力。
